# Верификация: богатство поколений / longevity economy / wealth transfer

Дата проверки: 2026-07-06. Метод: WebSearch (WebFetch недоступен), поиск первоисточников (Fed DFA/Z.1, AARP, Cerulli).

## Утверждение 1 — 55+ держат ~73% богатства США; бумеры ~51% (~$85–88 трлн, ФРС Q4 2025)
**Вердикт: УТОЧНЕНО (проценты верны, долларовая цифра занижена, «национальное богатство» → богатство домохозяйств)**

- Доля бумеров: **51.2% в Q4 2025** по Fed Distributional Financial Accounts (DFA) — «~51%» подтверждено.
  Источники: Statista (по данным Fed DFA) https://www.statista.com/statistics/1376620/wealth-distribution-for-the-us/ ; Fed DFA https://www.federalreserve.gov/releases/z1/dataviz/dfa/distribute/chart/
- Доля 55+: **~73%** — подтверждается несколькими вторичными источниками, ссылающимися на Fed DFA (возрастные когорты 55–69 + 70+).
  Источник: SmartAsset (на данных Fed) https://smartasset.com/financial-advisor/wealth-by-generation ; NBER Digest https://www.nber.org/digest/202511/shifting-wealth-us-age-groups
- Долларовая цифра: по Z.1 (релиз 19.03.2026) net worth домохозяйств+НКО в Q4 2025 = **$184.1 трлн**; 51.2% богатства домохозяйств ≈ **$88–90 трлн**. Washington Post/анализы Fed-данных: «almost $90 trillion by end of 2025»; IndexBox: $88.5 трлн. Диапазон **$85–88 трлн соответствует Q1–Q3 2025**, для Q4 2025 корректнее **~$88–90 трлн**.
  Источники: Fed Z.1 https://www.federalreserve.gov/releases/z1/20260319/z1.pdf ; https://www.washingtonpost.com/business/2025/11/18/baby-boomer-wealth/ ; https://www.indexbox.io/blog/baby-boomers-control-over-half-of-us-household-wealth-in-2025/
- Терминологическая правка: DFA измеряет **богатство домохозяйств (household wealth)**, а не «национальное богатство» в широком смысле.

## Утверждение 2 — Домохозяйства 50+ = 56% потребрасходов / 43–45% ВВП (AARP Longevity Economy)
**Вердикт: УТОЧНЕНО (цифры реальные, но из разных изданий отчёта; 45% не подтверждено; атрибуция Oxford Economics устарела)**

- **56%** («56 центов с каждого доллара») — данные **за 2018 г.** из AARP Longevity Economy Outlook 2019; там же прогноз роста до 61 цента к 2050.
  Источник: AARP https://www.aarp.org/pri/topics/work-finances-retirement/economics-aging/longevity-economy-outlook/ ; https://longevityeconomy.aarp.org/
- Свежее издание (Longevity Economy Outlook **2026**, данные 2024): 50+ дали **$12.5 трлн = 43% ВВП США** (в 2019-м отчёте было 40%/$8.3 трлн за 2018); потребрасходы домохозяйств 50+ = **$10.7 трлн в 2024 ≈ «более половины»** (~54% PCE), а не 56%.
  Источники: https://www.aarp.org/money/personal-finance/longevity-economy-report-2026/ ; snapshot PDF https://www.aarp.org/content/dam/aarp/research/surveys_statistics/econ/2026/longevity-economy-outlook-2026-snapshot.doi.10.26419-2fint.00401.059.pdf
- «43–45% ВВП»: подтверждается только **43%** (2024); верхняя граница 45% источником не найдена.
- Атрибуция: с **Oxford Economics** AARP делала первые издания (2013/2016); Outlook 2019/2026 — методология Economist (EIU / Economist Enterprise, модель REMI PI+). Писать «AARP/Oxford Economics» для текущих цифр некорректно.
  Источник: https://www.oxfordeconomics.com/resource/the-longevity-economy/ (издание 2016)

## Утверждение 3 — Cerulli: $124 трлн до 2048; ~$54 трлн — пережившим супругам, >95% женщинам
**Вердикт: ПОДТВЕРЖДЕНО**

- Cerulli (пресс-релиз, декабрь 2024, отчёт U.S. HNW/UHNW Markets 2024): всего **$124 трлн** до 2048 ($105 трлн наследникам + $18 трлн благотворительности; ~$100 трлн от бумеров и старше = 81%).
  Источник: https://www.cerulli.com/press-releases/cerulli-anticipates-124-trillion-in-wealth-will-transfer-through-2048
- Отдельный пресс-релиз Cerulli: «**$54 Trillion Will Transfer to Widows Through 2048 — More Than 95% Will Go to Women**» — горизонтальные (внутрипоколенческие) переводы супругам $54 трлн, из них >95% женщинам; ~$40 трлн — вдовам поколения бумеров и старше.
  Источники: https://www.cerulli.com/press-releases/54-trillion-will-transfer-to-widows-through-2048-more-than-95-will-go-to-women ; CNBC https://www.cnbc.com/2026/03/14/great-wealth-transfer-widowed-spouses.html ; NBC https://www.nbcnews.com/business/personal-finance/women-will-get-124-trillion-great-wealth-transfer-rcna196076
- Нюанс формулировки: $54 трлн — это часть внутри $124 трлн (сначала супругам, затем далее наследникам/благотворительности), а не отдельный поток.
