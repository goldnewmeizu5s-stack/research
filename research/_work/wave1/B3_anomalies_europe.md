## 0. Ограничения сессии (фиксируются как ограничение метода)

- Firecrawl (`firecrawl_search`, `firecrawl_research_*`) отдавал HTTP 429 при >5–8 параллельных запросах и держал окно блокировки ~8–10 минут (09:36–09:55 UTC). Далее запросы выполнялись пакетами по 3–5. Все страницы ниже, помеченные «открыто», реально получены в поле `description` результата Firecrawl в этой сессии.
- WebSearch: бюджет сессии исчерпан (200/200) на ~09:49 UTC. WebSearch использовался только для поиска URL; ни одно утверждение не опирается на сниппет WebSearch. Там, где страницу не удалось открыть через Firecrawl, утверждение помещено в раздел 4 (UNVERIFIED).
- Полный текст PMC-статей через `firecrawl_research_read_paper` был доступен только для arXiv-статьи (Dahl et al., 2312.11481); для PMC-статей читались абстракты из `search_papers` (T1, цитировать можно только абстракт).
- Не открывались (заблокированы прокси / не проиндексированы): WHO IRIS (good practice brief по Венгрии), WCRF NOURISHING, GINA — поэтому подсчёт уникальности опирается на рецензируемые обзоры (PMC) и на открытые правовые базы.
- Исландия, страны Балкан, Кавказ: кандидатов с открытым первичным источником не найдено в рамках лимитов сессии (см. раздел 4).
