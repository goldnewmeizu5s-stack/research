# B6 - anomaly-scan по 12 категориям (кросс-региональный, весь мир)

Сборщик: B6 (collector). Дата доступа ко всем источникам: 2026-09-04. Определения - `00_definitions.md` 2.3, правила - раздел 3.

Каналы, реально использованные в сессии: `mcp__Firecrawl__firecrawl_search` (site: + ключевые слова, highlights) - основной канал открытия страниц; `mcp__Firecrawl__firecrawl_research_search_papers` (PubMed/PMC-абстракты = T1); `firecrawl_research_read_paper` - для всех запрошенных статей вернул "no full-text passages" (использованы только абстракты); `WebSearch` - только для discovery (бюджет сессии 200/200 исчерпан на 7-м пакете, дальше discovery шёл через сам Firecrawl). WebFetch/curl не использовались (все целевые домены вне github/S3).

Ограничения сессии: Firecrawl-search периодически отвечал 429 (общий лимит с параллельными сборщиками) - работал пакетами по 3-8 запросов; часть первичных документов (Gazzetta Ufficiale IT, fedlex CH, gov.il, dm.gov.ae, normattiva) вернули пустой `description` - такие меры помечены как "первичный текст не открыт" и уровень источника понижен.

Условные обозначения: T1/T2/T3 - уровни источников (3.1); HIGH/MEDIUM/LOW/UNVERIFIED - уверенность (3.2). "РП" = распространённая практика (>5 стран с аналогом) - НЕ аномалия по 2.3, если нет уникального элемента конструкции.
