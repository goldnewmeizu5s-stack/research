# Верификация: Germany_EU_Italy (независимый верификатор)

Дата доступа: **2026-09-04**. Каналы: firecrawl_search (все домены кроме github/S3). WebSearch недоступен, WebFetch для не-GitHub заблокирован.
Первичные базы, использованные для проверки: gesetze-im-internet.de, g-ba.de, eur-lex.europa.eu, curia.europa.eu, gazzettaufficiale.it, senato.it, normattiva.it, PubMed/PMC.

> Примечание о канале: firecrawl_search возвращает title/description/highlights страницы, а не полный DOM. Там, где ниже приведён «дословный фрагмент», он взят из текста, отданного поисковым индексом по конкретному URL (или по документу того же домена/акта). Случаи, когда точная страница-URL из брифа не отдала текст, помечены отдельно.
