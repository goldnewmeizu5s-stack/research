Дата доступа всех источников: **2026-09-04**. Инструменты: `mcp__Firecrawl__firecrawl_search` (по одному вызову за раз, `highlights: true`), `mcp__Firecrawl__firecrawl_research_inspect_paper`, `mcp__Firecrawl__firecrawl_research_read_paper`. WebSearch не использовался (недоступен). Ничего из памяти модели.

Метод для C3: для каждого кластера повторены заявленные верификационные запросы раздела 5 файла C3 (V01-V40) с теми же операторами `site:` и тем же `limit`; записано фактическое число результатов; открыт минимум один доказательный URL (результат выдачи с описанием/фрагментом); проверено покрытие >= 2 платформ (разных доменов); проверено отсутствие чисел объёма поиска / CPC / difficulty без инструмента.

Метод для C4: для отобранных числовых утверждений источник открыт через `firecrawl_research_inspect_paper` (paperId `pmcid:` / `pmid:`) либо `read_paper`; для FAQ-страниц организаций - `firecrawl_search site:домен ключевые слова`; дословный фрагмент до 25 слов.
