## Ограничения каналов (зафиксировано)

1. WebFetch усекает CSV dominicroye/obesity: доступна только часть до строки `Marshall Islands,MHL,198…`; страны от Micronesia до Zimbabwe недоступны, полный пересчёт ранга невозможен. Модель WebFetch выдавала противоречивые значения для одной и той же строки в разных вызовах — цитировать только строки, полученные с явной инструкцией «дословно / НЕТ В ТЕКСТЕ».
2. s3-eu-west-1.amazonaws.com/wof-files/World_Obesity_Atlas_2025_rev1.pdf и World_Obesity_Atlas_2022.pdf не индексированы Firecrawl (запросы site: дают 0 результатов); использованы копии v7 (data.worldobesity.org), зеркала fs.knesset.gov.il, scribd.com, cdn.ncpodcast.net. Скоркарды по странам извлекаются фрагментарно — цифры Египта для Atlas 2025/2023 из PDF не получены.
3. pubmed.ncbi.nlm.nih.gov/41839719 через Firecrawl не открылся (0 результатов); метаданные подтверждены индексом research_*; полный текст в индексе отсутствует; текст открыт на ResearchGate.
4. Один ответ 429 от Firecrawl (запрос по Atlas 2022) — повтор успешен.

Прирост +6.5 п.п. (+25.5% относительно) арифметически верен; ранг «делит 6-е место» верификатором не подтверждён и требует пересчёта сборщиком по полному файлу (среди проверенной половины стран три имеют больший прирост).

Их нельзя смешивать с age-standardized 18+ оценкой WHO (32.0% за 2016).
- Население 2023: цитируемый GitHub-CSV даёт 106.8 млн (устаревшая версия WDI); 114 535 772 — текущая WB WDI / UN WPP. Исправить ссылку.
