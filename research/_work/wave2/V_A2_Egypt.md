# V_A2_Egypt — независимая верификация утверждений сборщика (Egypt, диабет)

Дата доступа: 2026-09-04. Верификатор работал без доступа к файлам проекта; только по списку утверждений и URL.
Каналы: WebFetch (только github.com / raw.githubusercontent.com), mcp__Firecrawl__firecrawl_search (site:домен, highlights, categories pdf/github), mcp__Firecrawl__firecrawl_research_inspect_paper / read_paper (PubMed/PMC). WebSearch недоступен. Ничего из памяти.

Контекст метрики (задан постановщиком): NCD-RisC Lancet 2016, распространённость диабета 18+, age-standardised, по полам; «оба пола» = простое среднее Men/Women; окно 2004 -> 2014. IDF — вторичная колонка (взрослые 20-79).

## 0. Важное замечание о канале WebFetch для CSV NCD-RisC

1. URL с веткой `main` — HTTP 404. URL с веткой `master` — файл существует.
2. Первый вызов WebFetch (master) вернул «строки Egypt» со значениями 0.0876/0.1038/0.0809/0.0952. Повторный вызов с требованием скопировать все строки Egypt дословно показал: содержимое обрезано (`[Content truncated due to length...]`) на странах Afghanistan…Cambodia, строк Egypt в полученном тексте НЕТ. Следовательно, первый ответ — артефакт суммирующей модели, а не содержимое файла. Эти числа НЕ используются ни как подтверждение, ни как опровержение.
3. Единственная дословно подтверждённая информация из файла: заголовок `"Country/Region/World","ISO","Sex","Year","Age-standardised diabetes prevalence","Lower 95% uncertainty interval","Upper 95% uncertainty interval"` и первые строки Afghanistan (например `"Afghanistan","AFG","Men",1980,0.0447123404542614,0.0153388298305608,0.0949179068380403`). Формат (доли 0-1, 95% UI) соответствует описанию сборщика.
4. Файл population.csv (datasets/population, main): открыт, но обрезан на строке `Cuba,CUB,2013,11298167`; строки "Egypt, Arab Rep." в полученном тексте нет.

## 4. Вывод по стране (устойчив ли рост)

Факты из открытых источников (все — оценки, разные определения и возрастные группы, прямо не сопоставимые):
- WHO country profile 2016 (18+, age-standardised, 2014): males 14.2%, females 18.2%, total 16.2%.
- PMC8472500 со ссылкой на WHO: Egypt 2014 — 17.9% (третье место в MENA).
- IDF (20-79, age-standardised): 16.6% (2011, пересчёт 11-го изд.) -> 20.9% (2021, 10-е изд.) -> 22.4% (2024, 11-е изд.); crude 18.4% (2021). Число людей: 7,323.4 тыс. (2011, пересчёт 11-го изд.) -> 10,930.7 тыс. (2021) -> 13,214.5 тыс. (2024).
- Локальные измерения: Alexandria (публ. 2018) age-adjusted 16.8%; Sohag 2019 (50+) 20.9%; STEPS 2017 raised blood glucose 15.5%.
- Самоотчётные/опросные: EDHS 2008 3.48% -> EHIS 2015 4.83% (рост, но уровень в 3-4 раза ниже измеренного).

Наша оценка: направление роста распространённости диабета в Egypt согласуется по всем открытым независимым источникам (WHO 2014 -> IDF 2021/2024; рост 2008->2015 в опросных данных; высокие локальные измерения 2017-2019). Однако конкретные значения NCD-RisC 2004/2014 по полам (A2-001…A2-004) и производные от них (прирост +4.47 п.п., +33.3%, ранг «место 1») остаются UNVERIFIED: первичный файл не открыт до строк Egypt. Единственное независимое совпадение — 17.9% для 2014 г. (оба пола) в PMC8472500, тогда как профиль WHO 2016 даёт 16.2% — расхождение 1.7 п.п. между двумя WHO-производными числами не объяснено открытыми страницами. Рекомендация: до подтверждения строк CSV (через curl/gh или страницу ncdrisc.org) считать тренд 2004->2014 качественно правдоподобным (MEDIUM по направлению), но численно неподтверждённым (LOW/UNVERIFIED по величине).
