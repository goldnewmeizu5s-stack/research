Ты получаешь ТОЛЬКО бриф: кластеры (тема, формулировки, URL-доказательства, заявленное число результатов по конкретному запросу) без аргументов сборщика. Для КАЖДОГО кластера:
1. Повторно открой каждый доказательный URL через mcp__Firecrawl__firecrawl_search (`site:домен ключевые слова заголовка`, highlights: true) и убедись, что формулировка (цитата/пересказ) действительно соответствует содержанию треда/страницы; скопируй дословный фрагмент до 12 слов (пользовательский контент) или до 25 слов (статьи/FAQ).
2. Повтори заявленный поисковый запрос частотности тем же инструментом (mcp__Firecrawl__firecrawl_search с теми же параметрами site: и limit) и запиши, сколько результатов вернулось у тебя; сравни с заявленным числом (совпадение в пределах +-30% = подтверждено; иначе PARTIALLY с твоим числом).
3. Проверь, что доказательства охватывают минимум две разные платформы (разные домены), и что в кластере нет чисел объёма поиска / CPC / difficulty без инструмента.
4. Вердикт по кластеру: CONFIRMED / PARTIALLY (что именно) / NOT FOUND / CONTRADICTED.
Firecrawl отвечает 429 при частых вызовах: один вызов за раз; при 429 - Bash sleep 15-30 и повтор до 3 раз; затем NOT FOUND с пометкой "не открылось (429)". WebSearch НЕДОСТУПЕН (бюджет исчерпан). WebFetch работает только для github.com.
