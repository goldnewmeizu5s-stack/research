Для КАЖДОГО утверждения из брифа ты обязан:
1. Открыть указанный URL и убедиться, что именно эта цифра/формулировка там присутствует; скопировать дословный фрагмент (до 25 слов). Каналы открытия: (а) github.com / raw.githubusercontent.com - через WebFetch или Bash curl (скачай CSV в /tmp/claude-0/ и проверь значение кодом Python: точная строка/ячейка; для утверждений о рангах/изменениях пересчитай изменение сам из значений CSV); (б) публичные бакеты *.amazonaws.com - Bash curl (скачай PDF в /tmp/claude-0/, извлеки текст `python3 -c "import pymupdf..."` (pymupdf установлен) и найди страницу с фрагментом); (в) все остальные домены - ТОЛЬКО mcp__Firecrawl__firecrawl_search (запрос вида `site:домен ключевые слова из утверждения`, highlights: true, limit 5-10; для PDF добавь categories: ["pdf"]); поле description результата содержит текст страницы; для статей PubMed/PMC также mcp__Firecrawl__firecrawl_research_inspect_paper / read_paper (paperId вида pmcid:PMCxxxx или pmid:xxxx). WebFetch для не-GitHub доменов заблокирован - не трать попытки. WebSearch НЕДОСТУПЕН (бюджет сессии исчерпан) - для поиска альтернативных источников используй mcp__Firecrawl__firecrawl_search без site: (обычный запрос) и затем с site:домен для открытия найденной страницы. Firecrawl отвечает 429 при частых вызовах: делай не более одного вызова за раз, при 429 - пауза (Bash sleep 15-30) и повтор, до 3 раз.
2. Найти минимум один АЛЬТЕРНАТИВНЫЙ или противоречащий источник на другом домене (national survey, WHO/IDF/NCD-RisC страница, PMC-статья, World Obesity Federation Global Obesity Observatory data.worldobesity.org, CDC, OECD и т.п.), открыть его тем же способом и привести дословный фрагмент со значением, годом, возрастной группой и типом показателя (crude / age-standardized).
3. Вынести вердикт: CONFIRMED (фрагмент найден дословно, независимый источник согласуется в пределах округления или расхождение полностью объяснено другой метрикой/годом), PARTIALLY (найдено с расхождением - объясни: другой год, метрика, округление, статус), NOT FOUND (URL открыть не удалось или фрагмента там нет), CONTRADICTED (открытый источник противоречит). Если Firecrawl вернул 429/пусто - повтори через паузу (Bash sleep 20) до 3 раз, затем NOT FOUND с пометкой "не открылось (429)". Не додумывай.
