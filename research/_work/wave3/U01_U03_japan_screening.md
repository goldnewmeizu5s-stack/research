### Итог U01

- **N (точный аналог) = 1** — Южная Корея (и то с двумя оговорками: единственный страховщик вместо ~3 400 японских; отсутствует обязательная программа вмешательства, эквивалентная 特定保健指導; периодичность 2 года).
- **M (похожая мера) = 7** — Россия, Тайвань, Казахстан, Китай, Сингапур, Германия, Франция.
- **Нет аналога: 5** — США, Финляндия, Бразилия, ОАЭ, Саудовская Аравия.
- Источник подсчёта: собственный подсчёт по 13 проверенным странам из первичных правовых баз (e-Gov, law.go.kr, laws.mol.gov.tw, adilet.zan.kz, normativ.kontur.ru/garant, g-ba.de, ameli.fr, healthhub.sg, nbphsp.org.cn, uspreventiveservicestaskforce.org, gov.br, tyosuojelu.fi, u.ae, istitlaa.ncc.gov.sa) + рецензируемые статьи (PMC5906184, PMC10854208).
- Уверенность: **HIGH** по Японии, Корее, России, Тайваню, Германии, Сингапуру (по два и более согласующихся T1/T2, страницы открыты, цитаты дословные). **MEDIUM** по Казахстану (один T1 + один T2), Китаю (один T1), Франции, Бразилии, ОАЭ, Саудовской Аравии.
- **Вердикт: АНОМАЛИЯ** (N = 1 ≤ 5). Даже при засчитывании всех «похожих» мер (N+M = 8) точная связка «обязанность каждого страховщика + обязательное измерение талии + обязательная программа вмешательства для 40–74» не воспроизведена нигде.

### Итог U02

- **N (точный аналог) = 0.**

- Источник подсчёта: собственный подсчёт по 13 странам; для Японии — 高齢者医療確保法 第120条/第121条 (диапазон коэффициента 90–110 %) и материалы МЗТБ (0000121283.pdf, 000761454.pdf).
- Уверенность: **MEDIUM**. По Японии — HIGH (T1-текст закона + два PDF МЗТБ). По остальным странам отрицательный вывод основан на отсутствии находок в открытых источниках, а не на исчерпывающем правовом поиске — это ограничение зафиксировано.
- **Вердикт: АНОМАЛИЯ** (N = 0 ≤ 5). Наша оценка: U02 — самая уникальная из трёх мер; конструкция «штраф/скидка страховщику по проценту охвата скрининга талии» не найдена ни в одной другой юрисдикции из проверенных.

### Итог U03

- **N (точный аналог) = 1** (Тайвань) **+ 1 с ограниченным охватом** (Россия — та же обязанность и тот же адресат-работодатель, но только для вредных/опасных условий и перечисленных отраслей, не для всех работников). Итого **N = 1–2** в зависимости от строгости критерия по охвату.
- **M (похожая мера) = 6** — Южная Корея, Саудовская Аравия, Бразилия, ОАЭ, Финляндия, (+ Германия/США классифицированы как «нет»).
- Источник подсчёта: собственный подсчёт по 13 странам на основе первичных правовых текстов (laws.mol.gov.tw, normativ.kontur.ru, casenote.kr/law.go.kr, gov.br, u.ae, tyosuojelu.fi, istitlaa.ncc.gov.sa) и МЗТБ Японии.
- Уверенность: **HIGH** по Японии, Тайваню, России, Корее; **MEDIUM** по Бразилии, Финляндии, ОАЭ; **LOW** по Саудовской Аравии (текст самой лаиха с перечнем пунктов не открыт, есть расхождение по дате вступления в силу).
- **Вердикт: АНОМАЛИЯ** (N = 1–2 ≤ 5). Обязательное измерение талии работодателем у всех штатных работников подтверждено только в Японии и на Тайване; в России — только для ограниченных категорий.

Наша оценка (интерпретация, не факт): три меры образуют связку, где уникальность нарастает от U01 (есть один близкий аналог — Корея) к U03 (один аналог — Тайвань, географически и институционально родственный японской системе производственной медицины) и к U02 (аналогов не найдено).
